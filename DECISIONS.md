# Decision Log

| # | Decision | Reason |
|---|---|---|
| 1 | Working name: Bare Scroll | Short and plain; not trademark-cleared yet |
| 2 | Android first | Accessibility and usage APIs make selective blocking possible |
| 3 | Block surfaces, not whole apps | Keeps useful parts of each app |
| 4 | Free core, no accounts | Anyone can use it |
| 5 | Local only data | Privacy by default |
| 6 | Never block when unsure | A miss is better than a wrong block |
| 7 | Emergency unlock waits | Stops impulse bypass but leaves a way out |
| 8 | Yearly numbers are projections | Honest labelling |
| 9 | Interface: flat black, white and grey, sans type | Calm; glow, gradients and serif type were tried and dropped |
| 10 | App logos: white for distracting, original colours for others | Makes the app list readable at a glance |
| 11 | Docs first, feasibility test before interface work | Blocking reliability is the main risk |
