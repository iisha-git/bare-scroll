# Bare Scroll

A free, open-to-everyone Android app that blocks the endless-scroll parts of social apps while leaving the useful parts alone.

> Status: planning. This repository holds product and technical documentation only. No application code yet.

## What it does

- Blocks Reels, Shorts and Spotlight, not the whole app.
- Blocks chosen YouTube channels, so the rest of YouTube stays usable.
- Blocks any website the user adds.
- Focus sessions with a timer and a locked mode.
- Emergency unlock that makes you wait before it opens.
- A short welcome that shows time spent today and what it adds up to over a year (clearly labelled as a projection).
