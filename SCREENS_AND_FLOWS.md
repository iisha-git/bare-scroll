# Screens and Flows

## Visual direction
Flat black background, white and grey only for the interface, clean sans type, pill buttons, normal app toggles, bottom tab bar (Today, Block, Focus, Stats). No glow, no gradients, no serif type. App logos: white monochrome for distracting apps; original brand colours for non-distracting apps.

## Screens
1. **Welcome 1: time used.** Large number for time or opens today, list of apps the user marks as distracting.
2. **Welcome 2: the year.** Yearly projection (labelled) as a 60-square grid.
3. **Today.** Opens, time given back, bars by hour, ring for progress.
4. **Block.** Toggles for Reels, Shorts, Spotlight; channel list; website list.
5. **Focus session.** Timer ring, apps allowed during the session (original colours), start and lock controls.
6. **Closed feed.** Shown when a blocked surface opens: "Closed right now", striped top edge, option to go back.

## Main flows
- **First run:** welcome, mark distracting apps, grant permissions, set first blocks.
- **Block a channel:** Block tab, add channel by name from a watched video, confirm.
- **Focus session:** Focus tab, choose length, optionally lock, start. Early exit uses emergency unlock.
- **Emergency unlock:** tap, reason prompt, countdown, unlock only after the wait.

## Notes
Design previews use sample numbers. Real numbers come from local events.
