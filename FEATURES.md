# Features

Priority: P0 must have, P1 should have, P2 later.

| Feature | Priority | Notes |
|---|---|---|
| Block Instagram Reels | P0 | Feed surface only; messages and posts stay open |
| Block Instagram Spotlight-style surfaces and Snapchat Spotlight | P0 | Same approach as Reels |
| Block YouTube Shorts | P0 | Shorts shelf and Shorts player |
| YouTube channel blocklist | P0 | Pick channels; videos from them are closed |
| Website blocklist | P0 | User adds any domain |
| Closed-feed screen | P0 | Shown when a blocked surface opens |
| Focus session | P0 | Timer; chosen apps closed until it ends |
| Emergency unlock with wait | P0 | A countdown before unlocking during a locked session |
| Welcome walkthrough | P1 | Two steps: time used, yearly projection |
| Today screen | P1 | Opens, time given back, day-by-hour bars |
| Year grid | P1 | Days of progress as a 60-square grid |
| Schedules | P1 | Recurring blocking windows |
| App picker with logos | P1 | Distracting apps shown in white monochrome; others in original colours |
| Stats history | P2 | Weekly and monthly views |
| Export and backup | P2 | Local file only |

## Behaviour notes
- Yearly figures are projections from recent averages and are labelled as such.
- Locked sessions cannot be ended by closing the app; only the delayed emergency unlock ends them early.
- Every block action is logged locally for the stats screens only.
